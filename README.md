# Coffee Shop Sales Analysis

A practice data analysis project using imaginary sales data.

## Question
Which drinks, hours, days and sizes make the most money?

## Tools
Google Sheets, pivot tables

## Data
18 sales over three days (October 1 to 3, 2026).
File: sales_data.csv

## Findings
- Best drink: Latte (27.50)
- Busiest hour: 8 o'clock (31.50)
- Busiest day: October 3 (37.50)
- Best size: Medium (44.50)

## Suggestions
- Hire more workers for the morning rush.
- Keep lattes and medium cups well stocked.
- Promote iced drinks at lunchtime.

## Limits
Only three days of practice data. A real shop needs three to six months.
